# Changes — 23 November 2026

**Deploy step:** run `npm run db:migrate` in `backend/` (adds `store_invoice_counters.last_transfer_number`). Nothing else changes in the database.

## Notifications (email PDFs)
- `backend/src/utils/simplePdf.js`: every table PDF now has a `#` index column, quantities left-aligned, money right-aligned, headings aligned like their figures, an optional totals row, and text sanitised for the PDF font (the "→" in transfer titles printed as "!'").
  Columns declare `type: 'qty' | 'money' | 'text'`.
- Goods received PDF now has batch, quantity, unit cost, selling price, line total and totals.
- New PDFs: stock adjustment, supplier payment, debit payment, daily summary, customer payment reminder (a statement per customer).
  Existing PDFs (sale, sales return, stock transfer, low stock, payments due) use the new alignment.
- Goods received notifications already carried a PDF in the normal flow. With GRN inspection ON no notification is sent when the inspection is done (unchanged; not part of this work).

## Goods received selling price
- A price typed at receiving is now always used (before, a store without batch-wise pricing silently replaced it with the previous batch's price).
- The price is saved to the default price category from Settings. If none is set, the store's first active price category is used (before: nothing was saved, so the Price List showed no price). Existing rows are updated, not duplicated.
- `backend/src/utils/priceCategory.js` (new); used by goods received, inspection and the Price List.
- The goods received form labels the field with the category, e.g. "Selling Price (WholeSale)".

## Stock transfer numbers
- New transfers are numbered per store: `TR-00001`, `TR-00002` … Older transfers keep their `TRF-…` reference.

## Screens
- Chart tooltips on reports show translated names ("Total Revenue") instead of keys.
- Daily Brief redesigned as a card (bottom sheet on phones). Escape closes it.
- Stock Count: equal-width columns (`DataTable` option `evenColumns`); added missing tab translations `count_stock`, `count_history`.
- Debits: summary cards use translated labels and whole-number counts.

## PDFs and exports (frontend)
- `exportUtils.js` / `ExportMenu.jsx`: table PDFs and the print view get a `#` column; money right, quantities left; headings aligned.
- Purchase order, delivery note, receipt (A4/A5/thermal), subscription receipt: same alignment and index numbers.
- Export button (permission-gated with the existing `export_*_pdf` permissions) added to: Debits, Sales Returns, Pending Orders, Goods Received, Purchase Orders, Purchase Returns, Stock Transfer, Stock Adjustment, Stock Count history, Stock Value History, Product Categories, Price Categories. `hooks/useListExport.js` (new) builds the export from the columns already on screen and exports every page of the current filters.
- Not changed: Excel/CSV exports have no `#` column; Messaging, Settings logs and Subscription have no export permission, so no export was added.
