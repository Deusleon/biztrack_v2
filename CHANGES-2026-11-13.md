# Changes — 13 November 2026

## Frontend
- **Faster start**: PDF / Excel / QZ Tray code loads only when used (export, receipt, delivery note, PO PDF, QZ print). Vite chunking is now a function in `vite.config.js` (react, network, lang-en, lang-sw, pdf, excel, charts, scan). Initial download ≈ 400 kB → ≈ 266 kB gzip; main app chunk 768 kB → 120 kB.
- `utils/pdfSettingsCache.js` (new) holds the PDF settings cache so Configuration does not load the PDF libraries.
- **Reports**: `pages/reports/layouts.js` (new) = columns, headings and totals per report (from the original BizTrack); Total row on screen + in PDF/Excel/CSV/Print; bar charts (top 10) added to 16 reports (19 reports now have charts); Day Report totals. `utils/exportUtils.js` reads the first number in a formatted cell when totalling.
- **QZ Tray** everywhere: `utils/qzReceipt.js` (new) used by Invoice, Pending order Sell, Sales History reprint and a new "Print with QZ Tray" button on the Receipt page.
- **Dashboard** for roles without the figures: `pages/DefaultDashboard.jsx` (new).
- **ErrorBoundary** (`components/ErrorBoundary.jsx`) at app level (`main.jsx`) and page level (`App.jsx`).
- **Lint**: 73 → 49 warnings, 0 errors (remaining 49 = `react-hooks/set-state-in-effect`, the load-on-open pattern).
- **New logo**: all app icons regenerated from the supplied logo (emblem on a white tile, same as before): `icon-192/256/384/512`, `icon-maskable-192/512`, `apple-touch-icon`, `favicon-16…128`, `favicon.ico`; icon cache-busting `?v=1` → `?v=2` in `index.html` and `manifest.webmanifest`. The full logo with the wordmark is in `public/logo-full.png`. `BrandMark` (login, sidebar) and the default receipt logo pick up the new icon automatically.
- **User Guide → Version 2**: new Version 2 cover with the new logo, new header logo and footer ("Version 2 · November 2026 Edition") on every page, Chapter 16 added to the contents; Chapter 16 added to both PDFs in `public/manuals` (English 41 pages, Swahili 42); in-app "What changed" notes replaced.
